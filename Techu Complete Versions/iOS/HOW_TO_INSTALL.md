# Techuboard for iOS (iPhone / iPad)

## 📱 আইফোন ব্যবহারকারীদের জন্য বিতরণ পদ্ধতি

Apple-এর কঠোর নিরাপত্তা নীতি (iOS Sandbox) অনুযায়ী, অ্যান্ড্রয়েডের মতো `.apk` ফাইল ড্রাইভ বা হোয়াটসঅ্যাপে পাঠিয়ে ডাবল-ক্লিকে আইফোনে কোনো অ্যাপ ইনস্টল করা যায় না।

### 🚀 যেকোনো আইফোন ব্যবহারকারীকে অ্যাপ দেওয়ার সেরা ২টি উপায়:

#### ১. Apple TestFlight (বিশ্বের স্ট্যান্ডার্ড ও সবচেয়ে সহজ উপায়)
* **পদ্ধতি:** অ্যাপলের অফিশিয়াল বিটা টেস্টিং টুল।
* **ব্যবহারকারীর সুবিধা:** আপনি শুধু একটি টেস্টফ্লাইট লিংক পাঠাবেন। ইউজার সেই লিংকে চাপ দিলেই তার আইফোনে অ্যাপ ইনস্টল হয়ে যাবে। কোনো টেকনিক্যাল সেটিংস বা কম্পিউটারের দরকার হবে না।

#### ২. AltStore / Sideloadly (বিনা খরচে নিজস্ব ডিভাইসে টেস্ট করার জন্য)
* ম্যাকবুক বা পিসির সাথে আইফোন ক্যাবল দিয়ে কানেক্ট করে সরাসরি `.ipa` ফাইল ইনস্টল করা যায়।
