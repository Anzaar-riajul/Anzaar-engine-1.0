# Techuboard — Complete Versions (All Platforms)

## 🎯 প্রোডাক্ট পরিচিতি (Ecosystem)
* **অ্যাপ নেম:** **Techuboard**
* **বাংলা ফনেটিক ইঞ্জিন:** **TechuAvro (টেকুঅভ্র)**
* **ক্রস-প্ল্যাটফর্ম সিঙ্ক ইঞ্জিন:** **TechuSync**

---

## ১. Android (অ্যান্ড্রয়েড)
* **ফাইল:** `Android/Techuboard-Android-v1.0.apk`
* **কীভাবে ব্যবহার করবেন:** ফাইলটি সরাসরি যেকোনো অ্যান্ড্রয়েড ফোনে পাঠাতে পারেন। ফোনে ফাইলে চাপ দিলেই ইনস্টল অপশন আসবে। ("Install unknown apps" অন করতে বললে এলাউ করে দিন)।

---

## ২. macOS (ম্যাকবুক)
* **ফাইল:** `macOS/Techuboard-macOS.zip`
* **কীভাবে ব্যবহার করবেন:** ফাইলটি আনজিপ করলে `Techuboard.app` পাবেন। এটি `Applications` ফোল্ডারে ড্র্যাগ করে ছেড়ে দিন এবং ওপেন করুন।
* *নোট:* প্রথমবার খোলার সময় Gatekeeper আটকালে রাইট-ক্লিক (বা Two-finger tap) করে "Open" চাপুন।

---

## ৩. Windows (উইন্ডোজ)
* **ফোল্ডার:** `Windows/`
* **স্ট্যাটাস:** উইন্ডোজের জন্য Flutter x64 বিল্ড স্ক্রিপ্ট প্রস্তুত রয়েছে (`scripts/package_windows.ps1` এবং `.github/workflows/release.yml`)। এটি থেকে সরাসরি `.exe` ও পোর্টেবল `.zip` ফাইল জেনারেট হয় যা উইন্ডোজে ডাবল ক্লিকে চালু হয়।

---

## ৪. iOS (আইফোন)
* **ফোল্ডার:** `iOS/`
* **বাস্তবতা ও নিয়ম:** অ্যাপল আইফোনে কোনো ফাইল পাঠিয়ে সরাসরি ডাবল ক্লিকে ইনস্টল করার নিয়ম রাখে না (Security Sandbox)।
* **সমাধান:** আইফোনে টেস্ট করার সবচেয়ে সহজ উপায় হলো **Apple TestFlight**। এর মাধ্যমে একটি সাধারণ লিংক পাঠিয়ে দিলেই আইফোন ব্যবহারকারী সরাসরি অ্যাপটি ইনস্টল করে নিতে পারে।
